# ชีวิต

เว็บเกมจำลองชีวิตภาษาไทย: เกิดมาเป็นคนหนึ่งโดยสุ่ม ใช้ชีวิตนั้นไปทีละปี และจบที่อนุสรณ์ ไม่มีการเลือกญาติหรือส่งต่อชีวิตให้คนรุ่นถัดไป ครอบครัวเป็นบริบทรอบตัวละครหลักเท่านั้น ฉากเริ่มต้นอยู่ในภาคอีสาน

## เริ่มเล่น

ต้องมี Node.js และ npm ติดตั้งอยู่

```sh
npm install
npm run dev
```

คำสั่งตรวจสอบ:

```sh
npm test
npm run lint
npm run typecheck
npm run build
```

เกมบันทึกชีวิตและสมุดสะสมไว้ใน `localStorage` ของเบราว์เซอร์นี้ ไม่มีเซิร์ฟเวอร์ในรุ่นแรก ข้อความของโลกที่ใช้ร่วมกันเป็นผลจากการจำลอง ไม่ใช่ผู้เล่นจริง

## โครงสร้าง

- `src/engine`: TypeScript ล้วนสำหรับการสุ่มกำเนิด เงื่อนไข การเลือกเหตุการณ์ ผลกระทบ และการจำลองชีวิตแบบ headless
- `src/content`: ข้อความภาษาไทย รายชื่อจังหวัด ชื่อ การ์ด และค่าปรับสมดุล
- `src/world`: อินเทอร์เฟซ `WorldService` และ `SimulatedWorld` สำหรับนับชีวิต เกิดใหม่ ดู cohort และเผยแพร่อนุสรณ์
- `src/ui`: Vue, Pinia, บันทึกในเครื่อง และภาพพิกเซล

ปีเกิดและปีจำลองเก็บเป็น ค.ศ. เพื่อรองรับช่วง 1950–2026 และปีคาดการณ์ หลังจากนั้นหน้าจอแสดงปี พ.ศ. โดยบวก 543

## เพิ่มการ์ดเหตุการณ์

1. เพิ่ม `Card` ใน `src/content/index.ts` ใช้ `Condition` แบบประกาศใน `when` และ `requires` หลีกเลี่ยงเงื่อนไขที่ทำให้ทางเลือกใช้ไม่ได้เพียงเพราะเพศหรือภูมิภาค
2. เขียนชื่อ เนื้อหา ตัวเลือก และข้อความประกอบเป็นภาษาไทย ทุกข้อความที่ผู้เล่นเห็นควรอยู่ใน `src/content`
3. การ์ดที่มี `pinnedYear` จะปรากฏเฉพาะปี ค.ศ. นั้น และเฉพาะตัวละครที่ยังมีชีวิตอยู่ในปีนั้น เหตุการณ์หลัง 2026 ต้องระบุว่าเป็นภาพสมมติ
4. เพิ่มการทดสอบเมื่อเพิ่มเงื่อนไขหรือกลไกใหม่ การทดสอบสุ่มจำลองตรวจว่าการ์ดเข้าถึงได้

## เพิ่มภูมิภาค

เพิ่มจังหวัดและโปรไฟล์ `RegionProfile` ใน `src/content/index.ts` รวมถึงตัวเลขการเข้าถึงโรงเรียน สถานพยาบาล และงานใน `src/content/balance.ts` ภูมิภาคใหม่ต้องใช้ interface เดียวกันเพื่อให้ `WorldService` และ engine ไม่ผูกกับหน้าจอ

## เพิ่มชุดเสื้อผ้า

ภาพใช้สไปรต์ 16×22 พิกเซลแบบเรียงชั้นใน `src/ui/portraits/sprites.ts` เพิ่มเลเยอร์ใหม่ใน `LAYERS` และรหัสสีใน `FILL` จากนั้นเลือกเลเยอร์ใน `src/ui/portraits/Portrait.vue` โดยให้ผลคงที่จาก id, ช่วงวัย, เพศ, อาชีพ, ยุค และภูมิภาค ภาพใช้ SVG แบบ `crispEdges`

## ตรวจสอบตัวเลขและวัฒนธรรม

ตัวเลขใน `src/content/balance.ts` เป็นค่าตั้งต้นเพื่อทดลองเล่น ไม่ใช่สถิติประชากรหรือข้อเท็จจริงทางสังคม แทนที่ด้วยข้อมูล NSO หรือ World Bank ก่อนใช้เป็นตัวแทนข้อมูลจริง ชื่อและเหตุการณ์มี `TODO(verify)` เพื่อให้ตรวจสอบกับผู้อ่านและชุมชนในพื้นที่ก่อนเผยแพร่
