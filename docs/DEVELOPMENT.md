# เอกสารสำหรับผู้พัฒนา

เอกสารนี้รวบรวมวิธีติดตั้งและรันโปรเจกต์ ตำแหน่งของระบบ และแนวทางแก้ไขเนื้อหาเกม

## เริ่มต้นทำงาน

ต้องติดตั้ง Node.js และ npm ก่อน จากนั้นรัน:

```sh
npm install
npm run dev
```

คำสั่งที่ใช้ตรวจสอบโปรเจกต์:

```sh
npm test
npm run lint
npm run typecheck
npm run build
```

## โครงสร้างโปรเจกต์

- `src/engine`: TypeScript สำหรับการสุ่มกำเนิด เงื่อนไข การเลือกเหตุการณ์ ผลกระทบ และการจำลองชีวิตแบบไม่ผูกกับหน้าจอ
- `src/content`: ข้อความภาษาไทย รายชื่อจังหวัด ชื่อ การ์ดเหตุการณ์ และค่าปรับสมดุล
- `src/world`: `WorldService` และ `SimulatedWorld` สำหรับนับชีวิต สร้างชีวิตในโลกจำลอง ดู cohort และเผยแพร่อนุสรณ์
- `src/ui`: หน้าจอ Vue, Pinia, การบันทึกในเบราว์เซอร์ และภาพพิกเซล

## เวลาเกิดและปีที่แสดง

ปีเกิดอ่านจากปี ค.ศ. ของนาฬิกาอุปกรณ์เมื่อสุ่มเกิด โดยบันทึกทั้ง `birthYear` (ค.ศ. สำหรับคำนวณอายุและการ์ดประวัติศาสตร์) และ `birthYearBE` (พ.ศ. สำหรับแสดงผล) ลงในผลสุ่มและเซฟชีวิต การกำหนดปีในการทดสอบทำได้ด้วย `rollBirth(seed, currentYear)` หรือ `vi.setSystemTime`

## เพิ่มการ์ดเหตุการณ์

1. เพิ่ม `Card` ใน `src/content/index.ts` ใช้ `Condition` แบบประกาศใน `when` และ `requires` หลีกเลี่ยงเงื่อนไขที่ทำให้ทางเลือกใช้ไม่ได้เพียงเพราะเพศหรือภูมิภาค
2. เขียนชื่อ เนื้อหา ตัวเลือก และข้อความประกอบเป็นภาษาไทย ข้อความที่ผู้เล่นเห็นควรอยู่ใน `src/content`
3. การ์ดที่มี `pinnedYear` จะปรากฏเฉพาะปี ค.ศ. นั้นและเฉพาะตัวละครที่ยังมีชีวิต เหตุการณ์หลังปี 2026 ต้องระบุว่าเป็นภาพสมมติ
4. เมื่อเพิ่มเงื่อนไขหรือกลไก ให้เพิ่มการทดสอบที่เกี่ยวข้อง การทดสอบสุ่มจำลองช่วยตรวจว่าการ์ดเข้าถึงได้

## เพิ่มภูมิภาค

เพิ่มจังหวัดและโปรไฟล์ `RegionProfile` ใน `src/content/index.ts` รวมถึงตัวเลขการเข้าถึงโรงเรียน สถานพยาบาล และงานใน `src/content/balance.ts` ภูมิภาคใหม่ต้องใช้ interface เดียวกัน เพื่อให้ `WorldService` และ engine ไม่ผูกกับหน้าจอ

## เพิ่มชุดเสื้อผ้า

ภาพใช้สไปรต์ 16×22 พิกเซลแบบเรียงชั้นใน `src/ui/portraits/sprites.ts` เพิ่มเลเยอร์ใหม่ใน `LAYERS` และรหัสสีใน `FILL` จากนั้นเลือกเลเยอร์ใน `src/ui/portraits/portrait.ts` โดยให้ผลคงที่จาก id, ช่วงวัย, เพศ, อาชีพ, ยุค และภูมิภาค ภูมิหลังค้าขายไทยเชื้อสายจีนใช้ `ox` ในวัยสูงอายุและ `ok`/`ap` ในวัยผู้ใหญ่ ส่วนงานเมืองและราชการใช้ `os`/`ol` ชุดชาวนาใช้ `ow`/`kr` และผ้าถุง `op` ภาพใช้ SVG แบบ `crispEdges`

## ตรวจสอบตัวเลขและวัฒนธรรม

ตัวเลขใน `src/content/balance.ts` เป็นค่าตั้งต้นเพื่อทดลองเล่น ไม่ใช่สถิติประชากรหรือข้อเท็จจริงทางสังคม หากจะใช้แทนข้อมูลจริง ควรแทนที่ด้วยข้อมูลจาก NSO หรือ World Bank ก่อน ชื่อและเหตุการณ์ที่มี `TODO(verify)` ควรตรวจสอบกับผู้อ่านและชุมชนในพื้นที่ก่อนเผยแพร่

## Deploy ไป GitHub Pages

1. สร้าง repository บน GitHub แล้ว push โปรเจกต์ขึ้น branch `main`
2. เปิด **Settings > Pages** แล้วตั้ง **Source** เป็น **GitHub Actions**
3. Workflow จะ build และ deploy เมื่อมี push ไป `main` หรือสั่งเองจาก **Actions > Deploy to GitHub Pages > Run workflow**

URL จะเป็น `https://<owner>.github.io/<repository>/` สำหรับ repository ทั่วไป หรือ `https://<owner>.github.io/` เมื่อชื่อ repository เป็น `<owner>.github.io`
