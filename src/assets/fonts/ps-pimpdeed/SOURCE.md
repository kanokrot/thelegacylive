# PS Pimpdeed Family

Font by touchie, downloaded from [ฟอนต์.คอม](https://www.f0nt.com/release/ps-pimpdeed-family/).

The archive contains five TrueType files: Pspimpdeed, PspimpdeedII, PspimpdeedIII, pspimpdeedIISM, and ps_pimpdeediiM. The site says downloading accepts its font license; see [the license](https://www.f0nt.com/about/license/). The site's general terms permit attaching font files to a program to make it render correctly and prohibit selling the font files themselves.
